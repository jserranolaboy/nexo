# Agentes

Hay dos líneas y no se contradicen.

El cliente actual está en `Core`, `Native`, `Web` e `iOS`. Sus reglas, formatos y pruebas se describen en `README.md` y `CONTRIBUTING.md`. No se borra ni se reescribe desde la reconstrucción.

La línea nueva está en `reconstruction/`. Ahí manda `reconstruction/AGENTS.md`. Un cambio de comportamiento nuevo no se copia también en `NexoCore` o en `Web/src/domain.ts`.

GitHub es el repositorio del código. No añade un backend, cuentas obligatorias ni un servicio de pago. La compatibilidad con el alfa VRR no se implementa en esta línea.
